# illustrator_scripts

Adobe Illustrator 用のスクリプト(ExtendScript / .jsx)をまとめて管理するリポジトリです。
複数PCへは、このリポジトリをクローン(または pull)してスクリプトフォルダを配置する運用を想定しています。

## 動作環境

- Adobe Illustrator CS6 (ExtendScript)

## 使い方

1. `scripts/` 内の `.jsx` ファイルを Illustrator のスクリプトフォルダにコピーします。
   - macOS: `/Applications/Adobe Illustrator CS6/Presets.localized/en_US/Scripts/`
   - Windows: `C:\Program Files\Adobe\Adobe Illustrator CS6\Presets\ja_JP\スクリプト\`
   - (バージョン/言語によりパスは異なります)
2. Illustrator を再起動します。
3. `ファイル > スクリプト` メニューから対象のスクリプトを実行します。

## スクリプト一覧

### RenumberText.jsx

選択した複数のテキストオブジェクトの中身を、位置順(上から下、同じ高さなら左から右)に連番で振り直します。算用数字・丸数字(①②③…20まで対応、それ以降は算用数字にフォールバック)・ローマ数字の3形式に対応し、開始番号と増分も指定できます。

**使い方**: 連番を振りたいテキストオブジェクトをすべて選択してからスクリプトを実行し、形式・開始番号・増分を順に入力してください。

### ExtractAllText.jsx

ドキュメント内の全テキストを、開かずにテキストファイルへ書き出します。誤字脱字チェック用にAI(Claudeなど)に貼り付けて確認する使い方を想定しています。各行は `[テキストフレーム名] 内容` の形式です。

**使い方**: チェックしたいドキュメントを開いた状態でスクリプトを実行し、書き出し先のファイル名を指定してください。

### AddBannerMargin.jsx

垂れ幕用に、アートボードの上下に指定値分の余白(縫い込み・グロメット等のための延長分)を追加し、元の仕上がり端の位置を「垂れ幕ガイド」レイヤー(非印刷)の点線で示します。

**使い方**: 対象のアートボードを表示した状態でスクリプトを実行し、上下に追加する余白(mm)を入力してください。

### ApplyOpticalKerning.jsx

選択したテキストオブジェクト(未選択の場合はドキュメント内の全テキスト)に、カーニング方式「オプティカル」(`AutoKernType.OPTICAL`)を一括適用します。

**使い方**: 対象を選択して(またはドキュメント全体に適用する場合は何も選択せずに)スクリプトを実行するだけです。

### CreateCornerTombo.jsx

角のみの日本式トンボ(内トンボ+外トンボがたすき掛けに重なる二重線)を、選択オブジェクトのバウンディングボックスを基準に作成します。
中央のセンタートンボ(十字マーク)は作成しません。

各角の座標は、Illustrator純正の「オブジェクト > トリムマークを作成」(環境設定「日本式トンボを使用」ON)が実際に生成するパスを実測して求めた値に基づき、手書きのパスとして描画しています。

- 対象: 選択オブジェクトのバウンディングボックス
- 塗り足し: 3mm
- トンボの腕の長さ: 9mm(塗り足し線からの延長分)
- 仕上がり線からのアキ: 0.5pt
- トンボ線の太さ: 0.1mm
- 線色: レジストレーションカラー(全版に印刷)。見つからない場合は K100% で代用
- 作成結果は「トンボ」レイヤー内の「角トンボ」グループにまとめられます

デフォルト値はスクリプト先頭の `BLEED_MM` / `ARM_LEN_MM` / `GAP_PT` / `STROKE_MM` を編集することで変更できます。

**使い方**: トンボを付けたいオブジェクト(またはアートボード上の仕上がり範囲を示すオブジェクト)を選択してからスクリプトを実行してください。

### PreflightCheck.jsx

ドキュメント全体を対象に、印刷入稿前によくある問題点を一括チェックしてアラートで報告します。選択は不要です。

- ドキュメントのカラーモードがRGBになっていないか
- 個々のオブジェクトの塗り/線にRGBカラーが使われていないか(CMYKドキュメントへの混入)
- アウトライン化されていないテキスト(ライブテキスト)が残っていないか
- エリア内テキストがオーバーフロー(はみ出し)していないか
- リンク画像でファイルが見つからない(パスが切れている)ものがないか

問題が見つからなければ「問題は見つかりませんでした」と表示されます。

**使い方**: チェックしたいドキュメントを開いた状態でスクリプトを実行するだけです。

### PrePrintCheck.jsx

印刷直前に行う最終確認・仕上げ処理です。`PreflightCheck.jsx`(確認のみ)とは異なり、検出結果を見せたうえで確認(はい/いいえ)を取ってから、実際にドキュメントを書き換えます。

- トリムマーク(レジストレーションカラーのオブジェクト)の確認(検出のみ、自動修正はしません)
  - 最前面のレイヤーにあるか(埋もれていないか)
  - 近くに暗い色のオブジェクトが重なっていて視認性が低くなっていないか(簡易判定)
- テキストのアウトライン化: 未アウトライン化のテキストがあれば件数を提示し、確認後に一括アウトライン化(`TextFrame.createOutline()`)
- アピアランスの分割: 確認後、ドキュメント全体に対して「アピアランスを分割」(`expandStyle`)を実行(効果のないオブジェクトには影響しません)

暗い色の判定は簡易的な目安(CMYKは平均インク量、RGBは輝度のしきい値)であり、正確な見た目判断ではありません。しきい値はスクリプト先頭の `DARK_CMYK_AVG_THRESHOLD` / `DARK_RGB_LUMINANCE_THRESHOLD` で調整できます。

**使い方**: 印刷直前のドキュメントを開いた状態でスクリプトを実行し、レポートを確認したうえで実行の可否を選んでください。

### NestShapesInArtboard.jsx

選択した複数の図形(曲線を含む自由な形状)を、バウンディングボックスではなく**実際の輪郭**が重ならない範囲で、現在のアートボードの範囲内にできるだけ詰めて配置します(実形状ネスティング)。凹んだ形状同士を互い違いに組み合わせるような詰め方も、輪郭の衝突判定によって自然に実現されます。

- 配置範囲: アクティブなアートボード
- 図形間の最小間隔: スクリプト実行時にダイアログで入力(mm)
- 配置順: 図形の面積が大きいものから順に配置
- 衝突判定: パスを直線近似した多角形どうしで、辺の交差・内包・最小距離をチェック。ハンドルがアンカーと同じ位置にある直線区間は端点だけを使い、曲線区間だけ分割するため、直線的な図形(多角形)ほど頂点数が少なく高速に判定できます
- 曲線の近似誤差対策: 曲線を直線近似すると、弦(近似の直線)は本物の曲線よりわずかに内側になるため、曲線を含む図形どうしが絡む場合だけ安全マージン(既定0.5mm、`CURVE_SAFETY_MARGIN_MM`)を追加の間隔として上乗せし、実際に重なることを防ぎます。直線だけの図形どうしは指定した間隔がそのまま使われます
- 探索方法: グリッド走査で上から下・左から右へ候補位置を探し、複数の回転角度(既定: 0/90/180/270度)を試しながら、最初に重ならない位置に配置
- 全体の寄せ: すべて配置し終わったあと、配置済み図形全体のバウンディングボックスをアートボードの左上角に寄せます(個々の配置の相対位置は変えず、全体を平行移動するだけ)。まとまった空きスペースが右側・下側に残りやすくなります
- 複合パスやグループ内の穴(内側のパス)は空きスペースとして扱わず、障害物として扱います
- 図形数が多い・曲線が複雑・グリッドが細かいほど計算時間がかかります。速度と精度は `CURVE_SEGMENTS` / `ROTATION_ANGLES_DEG` / `GRID_STEP_MM` で調整できます
- アートボードに収まらない図形や、パスを持たず対象外にしたオブジェクトがある場合はアラートで通知します

`scripts/extra/PackShapesInArtboard.jsx`(バウンディングボックスで詰める、高速)とは別のスクリプトです。矩形に近い図形ならそちら、輪郭を活かして詰めたい凹凸のある図形にはこちらを使ってください。

**使い方**: 配置したい図形をすべて選択してからスクリプトを実行し、最小間隔(mm)を入力してください。

### ArrangeShapesInGrid.jsx

選択した複数のオブジェクトを、名前順(名前に含まれる数字は数値として比較する自然順ソート、例: 「看板_2」→「看板_10」の順)に並べ替えたうえで、格子状(グリッド)に整列させます。

- セルの大きさ: 選択オブジェクトの中で最大の幅・高さに揃えるため、サイズがまちまちでも重なりません
- 各オブジェクトはセルの左上に揃えて配置します
- 列数・間隔(mm)はスクリプト実行時にダイアログで入力します(列数の初期値は正方形に近くなる数を自動提案)
- 基準位置: 実行前の選択オブジェクト全体のバウンディングボックスの左上

`GenerateSignsFromCsv.jsx` が斜めにずらしながら生成する複製(`看板_<ID>`)を、手直し前に整った状態で見渡せるようにする用途を想定していますが、汎用的に使えます。

**使い方**: 格子状に並べたいオブジェクトをすべて選択してからスクリプトを実行し、列数・間隔(mm)を入力してください。

## scripts/signage/ (看板デザイン自動化プロジェクト)

イベントの社名看板・誘導看板のように、同じレイアウトでテキストだけが違う看板をCSVデータから作成し、地図上に配置するためのスクリプト群です。「[看板デザイン自動化プロジェクト メモ]」の方針に沿って、以下の役割分担にしています。

- 社名や番号など規則性のあるデータ(看板の中身)は、テンプレートをCSVの行ごとに複製して自動生成する
- 看板の地図上の位置や向きは、現地の状況を見ながら人の目で手動調整する。データ(テキスト内容・向き)だけは表(CSV)と連携する

### GenerateSignsFromCsv.jsx

看板テンプレートを1つ選択して実行し、CSVファイルを指定すると、CSVの行ごとに看板を複製し、複製したテキストフレームへ値を直接書き込んで「生成した看板」レイヤーに配置します。各複製には`看板_<ID>`という名前が付きます。

(注: Illustrator標準の「変数」パネル/データセット機能は、1つのテンプレートを1件ずつ切り替えてプレビューする用途向けで、今回のように複数の看板を同時に並べて生成する用途には向かないため使用していません。)

**CSVを直して再実行した場合**: 同じID(`看板_<ID>`)が既にあれば、新しく増やさず中身だけ更新します。手動で動かした位置や、大きさなどの調整は保持されます。ID未入力の行はスキップします。

**準備するもの**: 看板テンプレートを1つのグループにまとめ、差し替えたい箇所のテキストフレームに、CSVの列名と完全に同じ名前を付けておく(例: テキストフレーム名「会社名」⇔CSVの列「会社名」)。CSVはExcelから「CSV UTF-8(コンマ区切り)」形式で書き出し、列名の1つを「ID」(大文字小文字は区別しない)にする。

### GenerateMapLabels.jsx

CSVの行ごとに、地図に貼り付けるための「ラベル(向きを示す三角アイコン+テキスト)」を一括生成し、「地図ラベル」レイヤーにグリッド状に並べて置きます。ラベルのテキストは、CSVの`ID`列・`角度`列を除く各列の値をつなげたものです。CSVに「角度」列(度、時計回り)があれば、アイコンの初期の向きに反映します。

配置(地図上のどこに置くか)は自動化せず、人が1つずつドラッグして配置する想定です。各ラベルにはID(`labelId`タグ)を記録しているので、あとから`SyncMapLabelsToCsv.jsx`で内容を照合できます。

### SyncMapLabelsToCsv.jsx

「地図ラベル」レイヤー内の各ラベルから、現在のテキスト内容と、アイコンの現在の向き(実際の形状から計算、タグの値には頼らない)を読み取り、CSVファイルに書き出します。位置(座標)は書き出しません。

Illustrator上で直接テキストを直したり、アイコンを手作業で回転させて向きを調整したりした結果を、表(Excel)側に反映させるための「保険」スクリプトです。

### scripts/signage/sample/ (動作確認用サンプル)

上記スクリプトを試すためのサンプル一式です。

- `CreateSampleDocument.jsx`: 実行すると新規ドキュメントを作成し、「テンプレート」レイヤーに看板テンプレート(テキストフレーム名「企業名」「業種」)、「地図」レイヤーに会場の枠を自動生成します。実行後は看板テンプレートが選択された状態になります。
- `sample-data.csv`: 上記テンプレートに対応するサンプルCSV(ID・企業名・業種の3列、10行)。

**試し方**: `CreateSampleDocument.jsx` を実行 → そのまま `GenerateSignsFromCsv.jsx` を実行して `sample-data.csv` を指定 → 「生成した看板」レイヤーに複製が並ぶことを確認、の順に試せます。並びを整えたい場合は「生成した看板」レイヤーの複製をすべて選択して `ArrangeShapesInGrid.jsx` を実行してください。地図配置は `GenerateMapLabels.jsx` を実行して `sample-data.csv` を指定 → 「地図ラベル」レイヤーのラベルを地図上へドラッグ → `SyncMapLabelsToCsv.jsx` で書き出し、の順に試せます。

## scripts/extra/ (使用頻度の低いスクリプト)

普段はあまり使わないが、必要になったときのために残してあるスクリプトです。`scripts/`直下ではなく`scripts/extra/`に置いています。

### PlaceSignsOnMap.jsx

「生成した看板」レイヤー内の看板(`看板_<ID>`という名前のオブジェクト、`GenerateSignsFromCsv.jsx`が生成するものと同じ命名)を、同じ名前(`<ID>`)を持つ地図上のマーカーの真上に、指定した縮尺で自動配置します。マーカー名との照合による自動配置方式で、「看板デザイン自動化プロジェクト メモ」の方針(人がドラッグして手動配置)とは異なるため、現在は`scripts/signage/`の主要ワークフローからは外し、参考用としてここに置いています。地図上に該当マーカーを用意すれば`GenerateSignsFromCsv.jsx`の出力に対しても動作するはずです(未検証)。

縮尺は実行のたびにダイアログで指定でき、何度でも再実行できます。前回適用した縮尺を看板オブジェクトのタグ(`signScale`)に記録しているため、再実行時も常に元のサイズを基準にした絶対倍率になり、縮小・拡大が累積してズレることはありません。

### PackShapesInArtboard.jsx

選択した複数の図形を、一定のスペースを空けながら現在のアートボードの範囲内に、できるだけ大きな1枚の矩形の空きスペースが残るように配置します(ギロチン分割法)。図形は必要に応じて90度回転させて配置されます。バウンディングボックス基準の高速な配置で、実際の輪郭に忠実な配置がしたい場合は`NestShapesInArtboard.jsx`を使ってください。

- 配置範囲: アクティブなアートボード
- 図形間のスペース: スクリプト実行時にダイアログで入力(mm)
- 配置順: 図形の面積が大きいものから順に配置。空き領域は矩形のリストとして管理し、図形を置くたびに「残った領域のうち大きい方が最大になるように」分割していく
- 回転: 90度回転させた方がよく収まる場合は自動的に回転させます(スクリプト先頭の `ALLOW_ROTATION` で無効化可能)
- アートボードに収まりきらない場合や、配置後に残った最大の空きスペースのサイズはアラートで通知します(収まらない図形があっても配置自体は続行されます)

**使い方**: 配置したい図形をすべて選択してからスクリプトを実行し、間隔(mm)を入力してください。
